# 六维证据覆盖校正

从 24,782 个登记样本的档案复算。数据来自 C31–C38 逐样本原始账本、C41–C50 包级正式验收记录和 272,602 个 S6 检查槽位。复算没有重新评价数据或调用模型。

## 算法

每项检查先按自身单位归一。P、F、U 分别为已通过、已失败和待判数，适用分母为 P＋F＋U，不适用单列。

| 指标 | 算法 |
|---|---|
| 已证实下界 | 100 × P / (P＋F＋U) |
| 可能上界 | 100 × (P＋U) / (P＋F＋U) |
| 证据覆盖率 | 100 × (P＋F) / (P＋F＋U) |

整项不适用时不参与维内平均。没有独立适用检查可计量的维度保留区间 0–100、覆盖率 0，状态仍为证据空缺。S6 局部组的适用子检查先归一再等权平均，整组作为一个计分项。维内对各适用独立检查或组等权，最后六维各占 1/6，以未舍入值计算。

下界只计已证实通过，待判不记通过或失败。上界展示待判全部通过时的边界。区间的适用范围限于登记检查，不能用于推断真实科学质量或统计置信区间。这是新的技术证据计量方法，正式六维评分仍按原批准规则进行。

## 去重与计入范围

| 维度 | 纳入范围 |
|---|---|
| 完整性 | 仅 C31 登记配对存在性。字段齐备、重复标注和取值自洽等全范围证据仍缺。 |
| 标注质量 | C32、C33、C34、C36、C37、C38。C33 缺独立类别真值，词表检查保留原状态，适用槽在本表改列待判。 |
| 样本对应 | 仅 C35，尺寸核对。不适用时没有独立适用检查，保留证据区间 0–100、覆盖率 0。 |
| 覆盖与分布 | S6-D1–D3 的局部一致性组，加 C41–C44 四项正式覆盖检查。 |
| 文档与来源追溯 | S6-T1–T4 的局部记录组，加 C45–C47 三项正式检查。S6-T5 哈希证据与 C45 有重合，只供诊断。 |
| 使用条件 | S6-U1、U3 的局部文件类型与模态组，加 C48–C50 三项正式检查。S6-U2 的可读性结果与 C31 配对存在性重合，只供诊断。 |

S6 组给出已执行的局部证据。C41–C50 覆盖正式目标、外部来源或授权等独立要求，仍按档案标记待判，不能由 S6 代判。

原局部六维观测分和含待核主榜情景分均单列。纳入候选计算主榜不会改写正式结论。正式六维总分仍为 0/12 可合分，缺证详见同级目录《12包正式验收》。

## 复算

从交付根执行，输出到外部新目录。

    python3 '13_六维评分修复_20261110/六维证据覆盖复算/recompute_sixdim_coverage.py' --root . --output /tmp/lth_sixdim_coverage_check

score.json 记录逐检查原四态、计分四态、分母、局部组、上下界与覆盖率。scores.csv 采用六位小数。程序核对原始样本账本 SHA-256，并比对正式报告的逐项计数和 S6 归档统计。
