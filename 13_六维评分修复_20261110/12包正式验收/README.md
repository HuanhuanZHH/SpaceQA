# 十二包正式六维验收记录

使用 11 月 9 日归档的全量推理、规则检查和 S6 观测。12 个发放包的标识和 TAR 摘要与发放清单核对一致。逐包验证原始评分卡、问题账本、样本账本和扩展检查证据的哈希，并验证 S6 样本身份及标注哈希。未对 12 包执行新模型前向或重新读取原始数据做全量评价。

每份报告给出六维验收状态、已有观察和所缺基准。已确认的限定观察保留在 observed 中，例如 C31 配对计数。C41–C50 引用归档实测及其实际待判原因。项目批准的权重为六维各 1/6。按现行合分条件，缺少任一完整维度依据时，正式总分留空。

查看《六维验收矩阵.csv》和《验收回执.json》。从交付根目录可以用以下命令独立复核归档证据，输出位置须为新目录。

    python3 13_六维评分修复_20261110/review_archive.py --output /absolute/new_archive_review
