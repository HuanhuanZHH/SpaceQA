# 12 包六维技术观测复算

本表使用已归档的 12 张评分卡、问题明细及 S6 逐样本证据。复算覆盖 24,782 个登记样本、10,817 条问题记录和 272,602 个 S6 检查槽位。没有新模型调用或重新评价原始 12 包。按已批准的六维等权，以未舍入维度分的算术平均得到六维技术观测总分。

## 六维计算范围

| 维度 | 范围 | 分母与计算 |
|---|---|---|
| 完整性 | C31，登记标注引用文件存在性 | 全部登记样本。100 ×（1 − 受影响样本数 / 登记样本数） |
| 标注质量 | C32–C38，类别、空间、时间、尺寸及对象标注检查 | 同上 |
| 样本对应 | C31、C35，文件对应和整图尺寸一致性 | 同上 |
| 覆盖与分布 | S6-D1–D3，声明对象数量、类别集合、时间区间一致性 | 通过与失败槽位。100 × 通过 /（通过＋失败） |
| 文档与来源追溯 | S6-T1–T5，标注头、版本、时间、方法和标注文件 SHA-256 | 同上 |
| 使用条件 | S6-U1–U3，文件类型、文件头可读性、模态声明 | 同上 |

前三维内，受影响样本是该维度确认计分样本与待核样本的并集。重复问题只按一个样本计。纳入待核是本次计分情景，问题明细仍沿用原始确认、待核状态。跨维度共享 C31、C35，衡量不同质量维度。独立的主排序使用整包确认及待核并集去重，各样本只计一次。

后三维从逐样本 S6 证据重计，和归档汇总逐项一致。不适用槽位单列，未计为通过。实测没有 S6 待定槽位。程序遇到待定槽位或无确定槽位时停止，以免将缺证换算成通过。S6 技术检查的通过率限定在所列范围。

完整六维正式分仍需可核验的独立标注参考及容差、适用样本的外部对应证据、目标覆盖和分布协议、独立来源链及用途授权。正式验收保留 0/12 可合分，详见上级目录的正式验收记录。六维技术观测总分和主排序分在各自字段中给出。

## 复核

从已解包的交付根执行下列命令，输出到外部的新目录。

    python3 '13_六维评分修复_20261110/技术六维复算/recompute_sixdim.py' --root . --output /tmp/lth_sixdim_check

score.json 保存每包每维的分子、分母、检查编号和证据引用。scores.csv 采用六位小数，空白的 fullQualityScore 表示正式总分待定。只使用 Python 标准库。
