# 六维评分修复说明

程序修复完成；完整六维验收仍缺目标协议及独立证据。此组件以 CPU 复算既有推理产物，不重新训练或冒充新的模型前向。R4 镜像及另一条 0.7.0 候选线未覆盖。

## 已修复

- 后三维的状态、分母、检查覆盖率和分数同步更新。
- 未知项留在适用分母；不适用需明确前提；不能靠删去未知项得到高分。
- 合成只接受六个正式维度、有限正权重及真实批准信息，逐项输出阻断原因。
- 支持外部只读协议和证据表，保留 EPB/ULF 平铺路径和 AIA 子目录结构，不修改原始数据。
- 整数和浮点测量均按有依据的容差比较；无期望哈希时待判定；受限许可中的 false 不当成缺失；CSV 检查读取完整文件。
- 新检查日志同时包含 ts、timestamp 和 event。

## 实测

34 项测试通过。三类真实小样各有 16 条登记样本，数据与标注共 32 个登记文件：C45 本地一致性、C50 解码均通过 31/32，缺失文件保留在分母。此比例仅对应小样，不能外推至完整数据包。其他证据不足项继续待判定。

完整六维分仍为空；原因不仅是权重，标注质量等前置维度仍缺独立参考。六维权重各 1（归一化各 1/6）已由项目用户于 2026-11-10 明确批准；这是项目采用的权重，并非官方或文献规定。批准记录见 approved_weight_policy.json。
