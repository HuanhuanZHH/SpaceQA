# 独立实测复核

直接按发放资料的规则核对原始输入，再与交付问题账本比较。复核过程和逐项证据可复算。

|检查|范围|确认|误报|漏报|计量核对|
|---|---|---:|---:|---:|---|
|C31 文件配对|十二包 24,782 个标注，按精确文件名和相对路径配对|272|0|0|272 个缺配对路径均与交付账本一致|
|C35 图像尺寸|4 个 EPB 包，3,150 个标注，其中 3,016 个可判|255|0|0|255 条标注哈希一致，声明宽高、实测宽高及偏差复算差为 0|

C31 仅读文件名清单。C35 对每个可配对图像读取 PNG 前 24 字节，另有 134 个缺图样本保留待判。精确率与召回率各为 100%，范围分别限于上述 C31 位置对照与 C35 可判定子集。正式评审的全类缺陷召回率和科学六维仍需独立参考。现行 12 包问题状态、排序和六维证据区间沿用封版数据。

## 复演

在提交根目录查看脚本参数，以只读发放数据与本包 findings.jsonl 为输入，将结果写入外部新目录。

    python3 08_运行日志/独立实测复核/c31/audit_c31.py --help
    python3 08_运行日志/独立实测复核/c35/verify_c35_epb.py --help

JSON 回执、C31 逐条位置、C35 逐样本尺寸证据与执行日志均随包附上。
