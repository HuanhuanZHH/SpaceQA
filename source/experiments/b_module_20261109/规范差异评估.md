# B 模块与当前 SpaceQA 规范的兼容性评估

## 结论

B 模块与当前系统的八类缺陷编号、四状态和证据回查方向一致，但 B 规范是面向 12 个路演包的窄口径账本规范，不能替代当前项目的六维总规范。集成时保留当前 `quality_evaluation_spec_v2` 作为总规范，把 B 作为 `B_omission_and_eight_class` 离线评估模块。

| 对照项 | 当前 SpaceQA 总规范 | B 模块规范 | 集成处理 |
|---|---|---|---|
| 六维 | 六维全部定义，覆盖分布、追溯和使用条件也有检查 | 只有前三维挂接缺陷码，后三维为空 | 以总规范为准；B 不生成六维综合分 |
| 八类缺陷 | L0-01、L2-G/P/T/F、L3-06/07、L3-MIS | 同一组编号 | 直接映射，兼容 |
| 状态 | 通过、不通过、待判定、不适用 | pass/fail/undetermined/not_applicable | 一一映射 |
| 定位容差 | 矩形 IoU、中心距离，多边形 IoU/Hausdorff，时间端点和尺寸误差 | 只对尺寸给出 0 像素精确判据，其他多为未定 | B 的 0 像素仅用于尺寸规则；其他定位继续使用总规范默认值并保留独立参考门控 |
| 专家异常值 | median+MAD，robust z>3.5 记录异常 | 未定义 | 继续由总系统处理；B 只消费冻结结果 |
| 计分 | 完整六维未闭合时给限定技术观测分或范围 | 3340 条 L2-P 原始词表记录、1690 个确认样本 | B 结果单独标记 `formalScoreMutation=false`，不覆盖正式分数 |
| 真值 | 官方 P/R/F1 需要独立逐样本真值和定位匹配 | 使用 P0/规则派生技术参考 | 所有 B 指标都携带 `independentScientificAccuracy=null` |

## 为什么算作有提升

B 的最新漏标策略在同一技术参考上把 Recall 从 34.43% 提高到 63.93%，F1 从 28.97% 提高到 34.98%，说明它对漏标候选的找回能力增强。Precision 从 25.00% 降到 24.07%，说明新增召回伴随误报，不能把 B 结果直接当作科学确认。统一八类微平均为 Precision 90.65%、Recall 94.40%、F1 92.49%。

因此 B 模块在系统中的位置是“候选增强和离线复评”，而不是无条件替换规则或正式质量分。前端和报告可以同时展示原正式口径、B 复评口径和全部疑点计入下界，三者通过版本字段区分。
