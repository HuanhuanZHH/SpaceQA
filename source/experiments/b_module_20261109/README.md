# B 模块兼容适配（2026-11-09）

本目录是 SpaceQA 生产源码的只读适配层。B 模块的完整复算材料位于交付根目录 `12_B模块集成_20261109/`，这里记录如何把它的输出登记到统一的实验/证据索引中。

## 设计

1. 正式规则、聊天前端和原 21 专家路径保持原样。
2. B 模块作为离线细分类与漏标评估插件，读取已经冻结的 B 结果，输出统一的模块清单。
3. `candidate`、`confirmed` 和 `lower-bound promotion` 保持不同状态；适配器不把模型候选自动写入正式质量分。
4. 结果必须携带版本、输入摘要、指标来源和独立真值限制，便于前端或报告按口径切换。

## 复算

```bash
cd 12_B模块集成_20261109/SpaceQA_B模块_最新漏标统一版_20261109
python3 source/verify_b.py
python3 source/report_metrics.py
```

该适配层不需要网络、API Key 或原始数据；重新训练仍需服务器上的私有数据、权重和 CUDA 环境。
