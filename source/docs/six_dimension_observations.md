# 六维技术观测评分规范 v1

版本：`six-observation-20261106-v2`。本规范提供输入文件与标注的六维技术观测画像。它补充原有八类缺陷检查，不改变缺陷确认状态、模型权重、污染指数或12包排序。

|维度|本次可复算范围|检查编号|
|---|---|---|
|完整性|数据存在、JSON可解析|S6-C1～C2|
|标注质量|当前任务类别词表、给定几何的有限性与非零面积、给定事件起止的可解析性与顺序|S6-A1～A3|
|样本对应|文件名、登记引用、显式声明尺寸|S6-P1～P3|
|覆盖与分布|声明对象数量、类别集合、观测起止的记录一致性|S6-D1～D3|
|文档与来源追溯|标注头文件名、版本、生成时间、方法、当前标注哈希链路|S6-T1～T5|
|使用条件|离线检查工具的格式、文件头可读性、模态接入约定|S6-U1～U3|

每条样本逐项保存`pass / fail / undetermined / not_applicable`。同一样本可贡献多条检查；计分单位是检查槽位，不是缺陷数量。所有检查等权。

共19项。时序数据无需虚构图像几何，采用事件起止结构检查；该项不判断科学真实端点或抖动。事件起止时区不一致而无法比较时保留证据未决。ULF类别从事件的`kind`字段读取，与图像事件的`event_type`分别适配。

设P为通过数，F为不通过数，U为证据未决数：

- 技术观测分：`100 × P / (P + F)`，仅在P+F>0时有数值。
- 限定指标完成比例：`(P+F)/(P+F+U)`。
- 含证据未决的得分区间：`[100P/(P+F+U), 100(P+U)/(P+F+U)]`。
- 不适用独立列示，不进入适用分母。未实现、缺路径、缺依据仍属于U，不能删分母、记通过或记失败。
- 非零面积容差为鞋带公式两倍面积大于`1e-8`；显式图像尺寸沿用原检查的逐像素比较；原始JSON和数据不修改。

六维卡片显示`displayScore`并明确标注“技术观测分”；原科学检查的`score`、判定覆盖与`formalScore`不被替换。满分仅表示当前限定指标通过，不认证完整科学质量。

覆盖分布没有总体采样目标，不能把自然不均衡当作错误；本次只核对输入中实际声明的数量、类别与时间。来源匿名化不扣分，记录链路分不认证真实观测机构身份。技术接入分不确认许可、再分发权、仪器定标或具体科学用途。

完整台账通过`/api/chat/sessions/<id>/six-dimension-evidence.jsonl.gz`下载，包含样本、检查编号、版本、通过状态、字段与文件位置、测量值和哈希。结构化报告与前端使用同一计算结果。

EPB的输入多边形与独立模型的矩形候选分别标明；当前模型没有可靠的独立分割边界。此次演示使用AIA矩形候选案例，不把EPB候选框当作分割结果。
