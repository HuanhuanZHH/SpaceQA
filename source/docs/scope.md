# 评价范围与后续扩展

当前产品评价已提供的科学数据集、标签、元数据和配套说明，输出质量问题、程度、项目规范下的评分与排序，以及可追溯证据。已有视觉训练属于质量缺陷检测器研发，不是通过下游科学模型的训练效果反推数据集质量。

正式交付范围明确排除以下工作：

1. 缺陷自动修复；输出整改建议时不改写原始数据或标签。
2. 下游模型训练效果评估，例如太阳活动预测或地磁科学任务的最终泛化效果。
3. 原始观测质量审核；无法凭当前数据核验的观测真实性、异常成因保留范围限制。
4. 仪器定标核验；PNG显示值不作为已校准的物理观测量。
5. 观测噪声成因判别；不把暗区、亮斑或波形异常直接解释为仪器或物理过程。
6. 跨源物理一致性核验；不同仪器或模态的物理因果一致性需要额外领域基准。

文件存在性、PNG解码尺寸、CSV列/点数/时间轴等属于当前数据的可机械检查内容。时间起点和物理单位需要明确可信锚点；单纯与公开P0不同或违反经验模式，不能自动当成无参照场景的科学错误。数据集类型用于选择适用规则与专家，包名和污染档位不作为缺陷判断输入。

后续可在获得数据授权、领域基准和人工核验后独立增加单位/定标模块、跨源一致性模块和人工审批的修复工作流，分别验证其指标和适用范围。大模型解释为可选服务，只组织已有检测证据，不改变检测状态和可复算分数。上述扩展不计入当前完成度。
