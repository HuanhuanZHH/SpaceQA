# 八类缺陷账本与六维质量报告

这一入口保留现有HGB7权重与服务，在其后补充细分检查、实例复核和可复算报告。不进行新训练。八类为L0-01、L2-G、L2-P、L2-T、L2-F、L3-06、L3-07、L3-MIS；旧L0-03合并到L0-01，同一文件不存在只算一次。

六个维度是检查框架，八类是内容缺陷。完整性和样本对应主要接收文件配对证据；标注质量接收类别、尺寸、位置、时间和漏/虚标证据；覆盖与分布另作空标注率、密度、类别和时间统计；来源追溯及使用条件另给来源/版本记录和分用途结论。不能把六维等同于八类，也不能把空标注率直接当漏标率。

## 检查和定位

`quality_ledger.analyze_sample`重新读取当前标注、核对引用文件存在性、PNG尺寸与声明字段，以及明确记录来源的任务类别契约。类别冲突定位到具体JSON Pointer，已有图形时同时给原始像素框。AR/EPB类别契约属于参赛方已声明判据；集合内类别不因此被认定为语义正确。ULF没有完整类别字典，不能因为出现另一种合法脉动名称就判错。

位置/覆盖/漏标/虚标/时间端点接收独立实例预测，使用已有`instance_audit`一对一匹配，转换为细分类别并计算像素、覆盖或秒差。模型无检出不能证明虚标。模型区域、LLM回答和结构化格式校验不等于科学真值。几何越界、时间反序等结构诊断与真实目标偏移、事件抖动分开存储。

`review_case(..., eight_classes=True)`和`review_mcp --eight-classes`提供八类约束。实际图像、label、专家概率、HGB和字段特征可进入复核；实例输出必须通过字段/坐标校验。失败按有界重试处理，仍失败保留待判。不改变旧九字段历史回执的复算结果。

## 分母、比例和程度

每包分母N是在检查前冻结的全部标注样本，缺文件、执行失败、待判均保留。逐类输出确认样本数k、实例数、四状态及待判u。

- 观测确认比例为k/N；只有全部适用样本完成该类判断时才给完整比例估计。
- 未完成时给观测范围[k/N,(k+u)/N]，不是统计置信区间；相对误差须有独立真值才计算，不能自证。
- 文件缺失程度为1；尺寸程度为两轴相对误差最大值，并保留像素误差。
- 类别程度为该样本中不符合类别契约的目标数/有可解析类别的目标数；不重复累加同一比例。
- 独立实例参考产生的几何程度为中心距离/图像对角线；覆盖程度为遗漏参考面积或多余标注面积比例；时间程度为两端点最大秒差。参考为预测时，程度仍是相对预测的候选测量。

严重程度只在同一缺陷、同一计量定义与单位内降序排列；相同程度保留并列。`问题个数×HGB概率/N`另称模型疑点负担，可能大于1，不是污染比例或物理严重程度。

## 评分、覆盖与排序

观测技术分=100×(1−不同确认问题样本数/N)。同一样本有多个问题只计一次，因此缺陷样本密度增大时不会出现分数上升。该分数评价数据包在已实现范围内的表现，不评价软件的比赛成绩。

六维分别给观测技术分、完整维度分、四状态、完成检查数和适用检查分母。未执行的适用检查保留在分母内；缺乏判据的完整维度分为null。模型候选不扣确认问题分。所有结论回查findingId、checkId、规则版本、文件、记录及区域；实例严重程度作为独立数值轴展示。

生成全局和类型内技术排序。不同类型的科学检查覆盖不同，因此这不是完整科学质量顺序；同技术分时，目录名只产生显示顺序，明确标注真实并列。不能以人为小数或目录名假装满足“不并列”。目前材料明确不含官方四计分单元q公式；取得该公式后应使用现有正式策略适配器，不能把本公式声称为官方q。

## 运行

服务器ML环境安装Pillow即可执行新包的机械部分，无须网络或新权重：

```bash
export PYTHONPATH=/path/to/spaceqa-agent/src
python experiments/rescue_20261104/run_roadshow.py \
  --input /path/to/EPB_seg_sample_abcdefghij --output /path/to/new-run
```

已登记的多包可用`--inventory-root`，可选`--hgb-root`复用既有HGB回执，复用不计作新模型前向。源数据不可修改，输出必须使用新目录。代码拒绝重复ID、歧义引用和输出覆盖。解析失败会留下失败文件并阻止把该包作为完整成绩输出。

八类MCP：

```bash
python -m spaceqa_agent.review_mcp --eight-classes --case-root /path/to/prepared-cases
```

实验程序`review_roadshow.py`支持当前图像/波形、JSON、全部21×3专家概率、HGB和字段；密钥只从服务器私有配置读取。24例实验只是格式、可定位性与成本试验，不能代表24,782条数据的八类F1。独立参考接入和定位指标由`instance_audit`提供。

## 复算

`samples.jsonl`保存逐样本八类四状态；`findings.jsonl`保存证据；`scorecards.json`保存汇总。仅根据逐样本账本即可复算：

```bash
python -m spaceqa_agent.quality_ledger \
  --sample-results /path/to/package/samples.jsonl --output /path/to/recomputed.json
```

汇总随机种子20261104，源文件哈希、程序哈希及环境在run.json。另对每包10%样本从原始标签和文件重新执行检查并比较；这是源证据与程序复算一致性验收，不是独立科学标注正确性验收。
