# SpaceQA 方案规划（交付源文件）

## 1. 目标与范围

SpaceQA 读取空间科学数据、标注和可选来源文档，输出八类内容缺陷、六维质量观测、逐数据集评分卡、全局排序和可回查证据。输入只读，原始文件不被修改；缺少独立真值时明确输出证据边界，不把候选写成官方 F1。

## 2. 数据范围

支持 AIA、HMI、CME、EPB、DMSP 图像/事件标注，以及 ULF CSV 时间序列和事件 JSON。扫描阶段建立文件、标签、样本、版本和 SHA-256 清单；同源版本按稳定样本标识分组，避免训练/验证泄漏。

## 3. 智能体构成

编排层采用确定性 pipeline。工具负责清单、配对、字段、尺寸、时间、覆盖和审计；技能文件承载领域判据和容差；规则文件约束失败降级、证据缺失、边界触发和禁止输出；记忆层只保存运行内上下文；插件默认关闭。当前正式评分不依赖外部模型 API。可选专家/LLM只能产生候选、定位或解释，不能改写评分和排序。

## 4. 评价方法

八类问题代码为 L0-01、L2-G、L2-P、L2-T、L2-F、L3-06、L3-07、L3-MIS。确定性规则直接核验文件缺失、引用、尺寸和可解析参数；需要独立参考的几何、漏标、虚标和覆盖结论在证据不足时标记待判定。六维规范、分母、容差、状态和类型对应关系以 `spec/quality_spec.yaml` 为唯一权威源。

## 5. 输出与回查

一次运行输出 `00_MANIFEST.yaml`、评分卡、排序表、问题清单、证据索引、运行日志、系统环境和随机种子。每条结论由 `findingId → checkId → evidenceRef → locator` 回查到文件、样本、标注记录、图像区域或时间区间。

## 6. 实施计划

当前已完成规则原型、八类账本、浏览器工作台、审计器和离线运行时。交付前冻结一次运行，复制全量结果，生成四份 PDF，完成 Docker 离线验收、A10 运行验收和五分钟视频。
