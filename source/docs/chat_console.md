# SpaceQA 对话式演示操作说明

## 1. 连接并打开页面

最方便的方法：双击`/path/to/spaceqa-agent\deploy\chat_console\launch.cmd`。已有健康连接时会自动打开浏览器；需要新建SSH连接时，保持出现的连接窗口打开，再打开下方欢迎首页。

也可以在本机 PowerShell 执行：

```powershell
powershell -ExecutionPolicy Bypass -File /path/to/spaceqa-agent\deploy\chat_console\connect.ps1
```

如果对方电脑没有 `icarus0` 配置，可使用新增的 IP 启动器，原有聊天页面和接口保持不变：

```powershell
.\deploy\chat_console\launch_ip.cmd
```

默认连接 `tangjiarui@222.195.72.220`，默认远端目录为
`/staff/tangjiarui/OPC/chat_console_20261105`。若账号或目录不同：

```powershell
.\deploy\chat_console\launch_ip.cmd 用户名@服务器IP /服务器上的chat_console目录
```

页面仍然是 `http://127.0.0.1:18780/chat.html?new=1`；案例库和九档样本档案在同一对话会话中，不会切换到另一套前端。

脚本会检查连接，并按需启动远端服务、建立SSH隧道。新建隧道时保持窗口打开；已连接时会打开浏览器并返回。

## 2. 建议的录屏顺序

1. **展示首页。** 页面只放一个EPB示例卡。把卡片拖入对话区，或直接点击它。
2. **展示总体结论。** 系统立即载入已有真实报告，页面注明“历史报告”、报告标签和原始评价时间。左侧新增该数据集的会话。
3. **说明数字。** 当前EPB示例登记787条样本，其中364条为确认问题样本、86条仅为待复核候选，去重检出450条，检出比例为57.179%。该比例是系统检出结果，并非真实污染率。
4. **查看九档样本档案。** 总览中显示“干净样本”和八类缺陷九张档案卡。点击任一卡片进入样本列表，列表显示真实数据文件名、缩略图或CSV波形入口；同一样本可以同时出现在多个缺陷档，避免强制单一归类。
5. **打开证据。** 点击样本卡即可查看原图/CSV、原始JSON标注、问题区域或字段指针和逐案分析。干净档样本也复用同一详情窗口。
6. **自然语言追问。** 例如：“主要有哪些问题？区分已确认问题和模型候选，并举一个能核查的样本。”等待回答完成，再继续提问。
7. **添加另一个数据集。** 点击左侧“新建数据集对话”→“服务器文件夹”→“路演测试数据”→选择单包→“添加并查看分析”。该目录直接列出真实12包。已有报告自动载入，无需重新跑评价。
8. **切换与返回。** 左侧只显示手动添加的会话，点击即可切换。点击左上角SpaceQA品牌返回欢迎首页，历史会话保留。

录屏讲解可用：

> 每个数据集对应一个独立会话。先读取已有评价报告，给出总体质量结论；再根据真实问题记录和证据回答追问。确定性问题与模型疑点分开展示，每项结果都能继续回查。

## 3. 报告载入、追问与重新分析

**已有报告**用于快速演示。本轮一次缓存报告API读取实测约0.125秒，这不是全部请求或完整评价的耗时保证。

**追问回答**已实测接通`deepseek-v4-flash-ascend1`，通过`grounded_llm`依据实际检查结果组织语言。界面显示“正在组织回答”时等待即可，避免重复发送。

最新真实浏览器验收记录：

| 操作 | 本次实测耗时 |
| --- | ---: |
| 拖入EPB示例并载入已有报告 | 0.270秒 |
| 从服务器目录添加AIA包并载入已有报告 | 0.104秒 |
| 依据结果生成一次自然语言回答（`grounded_llm`） | 26.894秒 |

以上是这三次具体操作的记录。载入报告与语言模型回答是不同步骤，耗时不代表重新执行完整评价，也不保证所有请求都在1秒内完成。

**重新分析**会真正创建评价任务，不用于快速录屏。没有已有报告的新包，以及新上传的ZIP，也会进入真实计算流程，耗时取决于数据量和检查内容。上传ZIP后会自动建立会话；大型数据包推荐直接从服务器文件夹选取。

本次对话接入没有产生新的F1提升实验。页面数量与分数来自检查结果，语言模型负责解释，不把待复核候选自动当成确认问题。

九档样本接口为`GET /api/chat/sessions/{session_id}/tiers?tier={clean|L0-01|L2-G|L2-P|L2-T|L2-F|L3-06|L3-07|L3-MIS}`。返回当前档的分页样本、文件名和同源预览地址；缺陷档允许多档交叉，干净档仅在完整执行且无问题记录时生成。

## 4. 服务器启动、检查与关闭

以下命令在本机PowerShell执行，使用现有`server` SSH配置：

```powershell
# 启动
ssh user@server '/usr/bin/python3 /path/to/chat-console/manage.py start'

# 查看状态
ssh user@server '/usr/bin/python3 /path/to/chat-console/manage.py status'

# 关闭本次对话服务
ssh user@server '/usr/bin/python3 /path/to/chat-console/manage.py stop'
```

只关闭本机连接时，在保持SSH隧道的窗口按`Ctrl+C`。关闭浏览器不会停止远端服务；远端服务用上面的`stop`管理。本次管理命令不停止其他已有服务。

## 5. 实现与排查

前端使用独立的`chat.html`、`chat.css`、`chat.js`，以中文对话方式访问会话、服务器目录、报告和上传接口。服务器目录由后端读取，并非本机文件选择器。

后端分析接口位于服务器本机8781，对话服务位于8782；本机18780通过SSH转发到8782。浏览器统一访问本机入口，无需直接暴露服务器端口。

- **页面打不开：** 先运行连接脚本，再打开欢迎首页；若新建了SSH隧道，保持对应窗口开启。
- **已有会话看不到示例：** 点击左上角SpaceQA品牌，或使用带`?new=1`的欢迎首页链接。
- **追问失败：** 查看界面提示并刷新会话确认状态，再重试；已有分析报告仍可查看。
- **选中新包后需要等待：** 该包可能没有已有报告，正在实际分析；查看进度与检查步骤。
